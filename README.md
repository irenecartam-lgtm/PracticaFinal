Introducción:

Esta práctica consiste en crear una web de viajes, donde se puedan crear, explorar y gestionar viajes.

Objetivos:

Para ello, primero miramos que secciones debíamos crear. Decidimos hacer 6: sección de la página principal, destinos populares, apartado de consulta con la IA, apartado del tiempo, quienes somos y ponerse en contacto con nosotras.

Estructura

En total hemos dividido el trabajo en tres partes: el índice principal, la sección de IA y la parte de gestionar los viajes propios. Es por eso que hay 3 html y cada uno con su respectivo css y java script. Así, se nos ha hecho mucho más fácil conectar cada pestaña y gestionar las funciones de cada parte.

Como estructura generar del índice principal, el Header continene todo los botones interactivos para accedera todas las secciones. En la página principal se observa una pequeña introducción y unas fotos. Luego tenemos la parte del carrousel, gestionada por arrays en el java script. A continuación pasamos a la parte de la IA, donde hay una introducción y un botón que nos lleva a otra pestaña. En clase, vimos como conectar la Api Key de la IA y cómo hacer que el chat respondiese
